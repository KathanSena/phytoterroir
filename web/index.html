    Location data carries real risk

    Coordinates become H3 cells on the server. The browser receives aggregate polygons and counts, never the raw records in live mode.

    GOVERNANCE FIRST

    Safeguards in this prototype

    • Live coordinates aggregate server-side before display.
    • Map has no individual occurrence markers.
    • Demo mode uses synthetic locations.
    • GBIF licensing and attribution vary by source record.
    H3 is not differential privacy. Sparse cells, external datasets or a high-resolution grid can still reveal sensitive locations. Get consent and establish community control, access restrictions and a threat model before handling protected data.
